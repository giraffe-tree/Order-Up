# Art Direction — Codex 会话可视化 × Overcooked 风格 3D 厨房

> 调研人：Art_Researcher ｜ 日期：2025-XX
> 目标：把 codex agent 会话渲染为 Overcooked（胡闹厨房）风格 3D 厨房。
> 1 会话 = 1 间厨房；1 agent = 1 位厨师；读文件/编辑/跑命令等事件驱动厨师在工位间跑动。
> 依据：6 张官方实机截图（见文末来源），颜色均用脚本从截图实际采样（采样值在文中标注"采样"）。

---

## 1. 摄像机

| 项目 | 结论 |
|---|---|
| 视角类型 | **透视相机（非正交）**，高位斜俯视。大多数关卡俯仰角 **55°–65°**（与地平面夹角）；部分关卡接近正俯视 75°–80°（ref-02 竹筏、ref-05 图书馆） |
| 方位角 | 固定正北（0°），不旋转；厨房长边平行屏幕底边 |
| FOV | 约 35°–45°（窄 FOV 弱透视，物体近大远小很轻微，接近"玩具模型感"） |
| 构图 | 厨房整体居中并略偏下，**顶部预留 ~12% 屏幕高度给订单票 HUD**，左下/右下角留给出分数与计时器；镜头随关卡大小整体缩放，不做跟随裁剪 |
| 推荐落地 | Three.js `PerspectiveCamera(fov=40)`，pitch 默认 **60°**，可暴露 55°–80° 档位；整厨房适配屏幕（fit-to-bounds），非追焦 |

## 2. 厨房布局（典型关卡空间结构）

- **网格制**：所有台面、地板严格按正方形网格排布（1 格 = 1 个台面模块）。厨师占地 ≈ 0.9 格。
- **主流结构 A — 中央岛台**（ref-01、ref-05）：房间中央 1–2 排岛台（放灶台/案板），四周靠墙一圈台面（食材箱、出餐口、水池），岛台与墙面之间是回字形走道。**走道宽 2–3 格**，2 格是下限（两厨师擦肩而过会卡位，正是游戏乐趣来源）。
- **主流结构 B — 双侧对峙**（ref-03、ref-04）：厨房被水道/裂缝/深渊分成左右两半，每侧 1–2 排台面，中间靠桥/传送带/移动平台连接。适合表达"会话被分成前后阶段"。
- **主流结构 C — 多平台**（ref-02、ref-06）：厨房拆成 2–4 个独立平台（木筏/甲板），平台间有间隙。适合表达"子代理/并行任务"。
- **工位排列惯例**：同一条台面线上，工位按"取食材 → 切 → 煮 → 装盘 → 出餐"流水线相邻排列；食材箱永远嵌在台面里（与台面同尺寸），不是独立家具。
- **竖向比例**：台面高 ≈ 0.9 格；墙高 1.5–2 格；厨师全高（含帽）≈ 1.1–1.2 格。

## 4. 厨师角色

- **头身比例**：约 **1 : 1.2–1.5**（头帽 : 身体），二头身 Q 版。**厨师帽体积 ≈ 整个身体**（ref-01 特写确认）：帽子是白色大灯笼/圆顶，几乎占剪影高度的一半。
- **厨师帽**：白色蓬松圆顶（球体压扁）+ 一圈帽檐（短圆柱），俯视时就是一朵大白圆。底部带极淡的蓝灰阴影面。
- **身体**：圆角柱形/梯形小袍子，**正面一块白色围裙矩形**；手臂是两根小圆棍 + 白手套圆球；腿几乎不可见（俯视被身体挡住），只做两只深色小鞋尖即可。
- **配色方式（=agent 区分手段）**：每位厨师一种**高饱和主题色**染袍子/帽子饰边，并在**脚下地面投一个同色圆环**（玩家指示圈，游戏里始终存在）。官方四色：蓝 `#447EE0`（采样）、红 `#E0473C`、绿 `#58B24C`、黄 `#F2C230`。头部皮肤/毛发可换（人类棕发、浣熊、熊猫、独角兽、鳄鱼……）——映射到 codex 场景可给不同 agent 类型配不同"头"。
- **动作风格**：小碎步快速平移（身体几乎不转，只平移+轻微上下颠簸）；搬运时双手前举把物品顶在头上/胸前；切菜时身体高频小幅抖动 + 白色"哒哒"粒子；跑动身后拖 2–3 团白色小方块烟尘。整体节奏夸张、弹性足（ squash & stretch ）。

## 5. UI / HUD

- **订单票（顶部，横排）**：白色/极浅蓝卡片，圆角 + 底部锯齿撕纸边；**卡顶一条彩色横条 = 剩余时间**（绿→黄→橙渐变消耗）；卡内最上方是大号主菜图标（放在白盘子里），中间一行**浅蓝灰小方格食材图标**（每格一种食材），最底部一个**黑色剪影图标**表示所需工序（锅/搅拌机/煎锅）。新订单从左侧滑入，整体略微重叠排列。（ref-03 特写确认结构）
- **分数（左下）**：金币圆形图标 + 白色粗体数字，下方小字 "TIP x N"。金币 `#F2C230` 描深边。
- **计时器（右下）**：`MM:SS` 白色超粗圆体数字 + 沙漏图标，数字下方一条**圆角进度条**（橙 `#F5A623` / 黄 `#F2C230`，随时间减少，尾段变红）。
- **字体气质**：超粗圆润无衬线（Baloo / Fredoka / VAG Rounded 一类），纯白填充 + 深色粗描边，轻微倾斜或弹跳动画。中文可用站酷快乐体/阿里妈妈方圆体一类圆体替代。
- **事件反馈**：灶台过热闪红色三角警告牌（白边红底 `!`）；物品可交互时头顶浮白色小图标气泡。

## 6. 整体调色板（12 色）

明亮卡通 + 饱和度适中的暖色基调（冷色只用于魔法/水体点缀）。hex 均来自截图采样或采样值微调：

| 用途 | hex |
|---|---|
| 木地板·浅 | `#D2A06B` |
| 木材·深（箱/梁/深色台面） | `#7A5230` |
| 台面·明黄 | `#FEC457` |
| 石砖·米 | `#B89B78` |
| 六边形砖·蓝灰 | `#879DC4` |
| 金属（锅/器械） | `#928688` |
| 水/魔法·青蓝（点缀） | `#39AEC1` |
| 火焰/加热·橙 | `#F57B4A` |
| 强调红（炉火芯/警告/计时尾段） | `#D94F3D` |
| 厨师蓝（玩家1，另配红 `#E0473C` 绿 `#58B24C` 黄 `#F2C230`） | `#447EE0` |
| 纸面/票卡·米白 | `#F5EBD7` |
| 描边/墙面深色·暗紫棕 | `#2A2138` |

打光建议：暖色主光（仿厨房顶灯/火把，色温偏 `#FFE0B3`）+ 环境光补亮阴影面；深色描边/深色墙把视线锁在厨房内（截图中外圈一律压暗）。

## 7. 低多边形 / 体素化还原建议（Three.js 盒体拼装）

基准：**1 地板格 = 1×1（世界单位）**，Y 轴向上。全部用 Box/Cylinder/Sphere 低面数拼装，不开平滑着色（flat shading），靠色块而非贴图。

| 物件 | 近似尺寸（宽×高×深） | 拼装要点 |
|---|---|---|
| 地板格 | 1 × 0.1 × 1 | Box；六边形砖可用 Cylinder(radialSegments=6, r≈0.56) 或直接方砖+描边 |
| 台面 | 1 × 0.9 × 1 | Box 主体 + 顶面板 1.05×0.08×1.05 外挑；侧面可加 0.02 深色描边框 |
| 灶台 | 台面 + 炉盘 | 炉盘 Cylinder(r=0.32, h=0.06, 20 段) 置台面顶；加热时叠 emissive 橙光盘 |
| 锅 | r=0.28, h=0.3 | Cylinder(16 段) + 两小 Box 锅耳；蒸汽 = 3–4 个白色小 Box 循环上升缩放 |
| 案板 | 0.6 × 0.05 × 0.4 | 白 Box 放台面；刀 = 0.3×0.02×0.08 银 Box + 0.12 深色柄 |
| 食材箱 | 箱 0.8×0.35×0.8 | 无盖木 Box（或 4 片围板）；正面挂 0.5×0.5 图标牌（CanvasTexture 画 emoji/图形即可） |
| 出餐口 | 台面 + 上方 1×1.2×0.15 窗框 | 窗框 4 根 Box 围边；可加深色"传菜洞"平面 |
| 盘子摞 | r=0.25, 每层 h=0.05 × 3–5 | Cylinder 叠放 |
| 传送带 | 1 × 0.85 × 1 每节 | 面板贴人字纹 CanvasTexture + UV 滚动动画 |
| 墙 | 1 × 1.5 × 0.3 每段 | Box；顶部可加盖 0.1 厚压顶条 |
| 厨师 | 总高 ≈ 1.15 | 身体 Cylinder(r=0.28, h=0.55)；围裙 = 身体正面贴 0.3×0.35 白 Box；帽 = Cylinder(r=0.30, h=0.22) + Sphere(r=0.32, 压扁) 圆顶；手 = Sphere(r=0.09)；脚 = 2 个 0.12 小 Box；**脚下圆环** RingGeometry(r=0.42–0.5) 贴地 |
| 厨师持物 | — | 物品（食材/盘/锅）挂在身体前方 0.35、高 0.75 处，随身体颠簸 |
| 走道 | — | 布局时保证台面行列之间留 **≥2 格**空格 |

比例校验：厨师体宽 0.56 ≈ 0.6 格，帽子直径 0.64，走在 2 格宽走道里两厨师正好擦肩——与截图一致。
